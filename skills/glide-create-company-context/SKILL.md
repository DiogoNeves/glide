# Glide Create Company Context

## Load

- `Glide HQ/AGENTS.md`
- `Glide HQ/Checklists/Company Context Setup.md`
- Existing README, website copy, product docs, pitch decks, customer notes, metrics docs, investor updates, and strategy notes when available

## Process

1. Inspect available materials before asking questions.
2. Draft `Glide HQ/Company Context.md` and `Glide HQ/Founder Brief.md`.
3. Ask what is wrong, missing, uncertain, and strategically important now.
4. Capture exact customer language when available.
5. Mark uncertain claims as uncertain.
6. Keep the first version useful, not exhaustive.

## Output

- Drafted or updated company context.
- Drafted or updated founder brief.
- Focused questions for high-impact gaps.
