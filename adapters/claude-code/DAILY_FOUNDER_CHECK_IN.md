# Daily Founder Check-In Prompt

Run `$glide-daily-founder-check-in` for this workspace.

Load company context, founder brief, follow-through ledger, decisions, questions, contradictions, relevant area files, and configured connectors. Prefer one useful question, risk, opportunity, contradiction, or follow-through nudge. Use two or three only when each is genuinely urgent or very important. Never surface more than three items. If more than three may matter, say: `Hey, there are other things that might be important. Do you want me to continue?`

During the first week, occasionally ask one light calibration question about signal, noise, timing, tone, length, missing context, or preferred action level.

Keep it short. Read/fetch is allowed when configured. Do not perform external actions without approval.
